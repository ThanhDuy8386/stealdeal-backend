# Development Database Backups

Put local SQL Server backup files here when you want to restore development data
into the Docker SQL Server volume.

Expected file names:

- `StealDealIdentityDb.bak`
- `StealDealNotificationDb.bak`
- `StealDealStoreDb.bak`
- `StealDealOrderDb.bak`
- `StealDealPaymentDb.bak`

Backup files are ignored by git.
